Universal Autonomous Voice AI Agents, Real-Time Speech Pipelines (STT/LLM/TTS), Conversation Design, Latency Optimization & Telephony Deployment Engine MCP Server for **Cursor, Claude Code, Windsurf, and Autonomous AI Agents**.

## 🌟 Core Capabilities:
- 👑 **Master 1-Shot Outcome Engine (`autonomous_voice_architect`):** Ingests the voice agent concept to synthesize a complete blueprint in one call: stack decision matrix (OpenAI Realtime API vs Pipecat vs LiveKit Agents vs Vapi/Retell), sub-800ms voice-to-voice latency budget, conversation architecture (turn-taking, barge-in, state), telephony vs web channel plan, per-minute cost model, and a production deployment roadmap.
- 🎙️ **Voice Pipeline Generator (`generate_voice_pipeline`):** Production real-time pipeline code — Pipecat Python bots with interruption handling, LiveKit Agents workers, OpenAI Realtime WebRTC browser clients, Twilio Media Streams bridges, and push-to-talk fallbacks — with VAD tuning, barge-in cancellation, and function calling from voice.
- 💬 **Conversation Flow Designer (`design_conversation_flow`):** Voice-optimized system prompts (short responses, spoken numbers, no markdown), turn-taking and silence policies, 4-level error recovery ladders, reliable structured data capture over voice, and human handoff triggers with whisper summaries.
- ⚡ **Latency Optimizer (`optimize_voice_latency`):** The sub-800ms voice-to-voice budget table (VAD, STT, LLM TTFT, TTS TTFB), streaming-first fixes (sentence-chunked TTS, prompt caching, speculative endpointing), and perceived-latency tricks that make agents feel instant.
- 🚀 **Telephony Deployment Kit (`prepare_voice_deployment`):** Twilio/Telnyx number provisioning, SIP trunk integration with existing PBX, recording consent and TCPA compliance checklists, observability plans (transcripts, latency histograms, interruption rates), per-minute unit economics, and a go-live checklist with a 60-second rollback kill switch.
